# Изолятор — Android 16

Начальная сборка интерфейса для Android 8+ (цель сборки Android 16 / API 36).

## Сборка APK
GitHub Actions собирает debug APK при push в `main`. Откройте вкладку **Actions**, выберите последний запуск **Build Android APK** и скачайте артефакт `izolyator-android16-debug-apk`.

## Важно
Это ранний прототип интерфейса: кнопка режима демонстрационная, а список приложений зависит от ограничений видимости пакетов Android. Приложение пока **не блокирует** сетевой трафик и не изолирует другие приложения. Реальная блокировка сети потребует корректно реализованного Android `VpnService` с согласием пользователя; полноценная изоляция обычно требует рабочего профиля, режима владельца устройства или root. Не используйте эту версию как защитный продукт.

## Технологии
- Kotlin
- Android Gradle Plugin
- compileSdk / targetSdk 36
